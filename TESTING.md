# Проверки

36 автоматических тестов прошли на Python 3.14.3 с aiogram 3.31.0. Docker настроен на Python 3.12; реальный запуск Telegram, Railway и Docker не выполнялся.

Проверены прежние выпуски, сохранность результатов, раздельные групповые карточки, возраст сообщений по календарю, порог точности 20 ответов, сортировка, защита от повторных/чужих ответов, неизменность вопроса после рестарта, отсутствие пропуска и повторных фраз.

Новые проверки подтверждают:

- любой пользователь с действительным приглашением может открыть карусель, включая отсутствующего в списке авторов;
- Telegram getChatMember не вызывается;
- неизвестный/поддельный токен приглашения не открывает карусель;
- обычные и отредактированные сообщения проходят через настоящий диспетчер aiogram без записи в базу;
- авторы вне исходного списка 13 человек импортируются, их имена входят в варианты ответа.

Отдельно база создана прежней версией карусели: результаты 9/10 в каждом из трёх выпусков, ответ карусели, текущий вопрос, список просмотренных сообщений и групповая карточка. После обновления всё сохранено, база расширена до 5 353 сообщений и 17 имён, повторный импорт ничего не меняет.

Сетевые отправки заменены тестовыми объектами. Фразы и правильные ответы тесты не печатают.
