# Проверки без спойлеров

Проверено локально на Python 3.14.3 с aiogram 3.31.0. Telegram API заменён тестовыми объектами; реальный бот и Railway из этой среды не запускались. Docker использует Python 3.12; отдельный запуск внутри Docker не выполнялся.

Все 20 автоматических тестов проходят:

- независимые игроки, группы и две игры;
- повторные ответы и одновременные нажатия;
- невозможность ответить за другого участника или пропустить вопрос;
- полный раунд, очки, отдельные рейтинги только завершивших;
- меню, переключение игр, ссылки на конкретную группу;
- восстановление прогресса и порядка вопросов после рестарта;
- сохранение результата 9/10 и существующих таблиц;
- удаление прошлой групповой карточки и редактирование при отказе Telegram;
- корректные имена и отсутствие раскрытого ответа до выбора;
- проверка пути SQLite внутри Volume на Railway.

Дополнительно база создана именно прежней версией проекта, затем открыта новой. Подтверждены: 9/10 завершённого игрока, незаконченная попытка с сохранённым ответом, неизменные вопросы и варианты, прежняя ссылка группы и ID групповой карточки. Новая игра создаёт отдельную попытку. `quiz-data.json` совпадает с предыдущей версией байт в байт.

Цитаты новой игры сверены с исходным экспортом по ID сообщений и ID авторов. Они не повторяют вопросы «Закончи фразу». Полный экспорт в архив не включён.

Запуск из папки проекта:

```sh
python -m unittest discover -s tests -v
python -m compileall -q bot.py storage.py questions.py config.py
```
