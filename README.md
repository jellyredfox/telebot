# Карусель Санька — по архиву, без прав администратора

## Обновление

1. Замените содержимое папки существующего репозитория файлами из архива, включая `bot.py`, `carousel.py`, `carousel-seed.db`, Dockerfile и tests. GitHub Desktop: Commit → Push origin.
2. Оставьте прежние Railway Volume, `DB_PATH` и `BOT_TOKEN`. Рабочую SQLite-базу не заменяйте файлом `carousel-seed.db`: бот сам однократно импортирует новые записи из него.
3. После деплоя откройте `/quiz` в группе и перейдите в личку → «🎠 Карусель Санька». Старые приглашения продолжают работать.

**Права администратора и изменения BotFather не нужны.** Версия не записывает обычные или отредактированные сообщения Telegram и не проверяет членство в группе. Играть может любой, получивший приглашение из исходной группы, в том числе пересланное. Отвечать за другого пользователя нельзя.

Репозиторий должен оставаться приватным: стартовая база содержит реальные фразы и ID авторов. Полного экспорта, фото и токена в архиве нет.

## Сообщения и авторы

Использован экспорт до 11 октября 2026. Проверены все отправители: 17 пользовательских аккаунтов, из них у 16 есть подходящие сообщения. Combot, бот предсказаний и сам бот викторины исключены. В наборе **5 353 сообщения**; на начало 15 октября **4 986** достаточно старые, 367 ещё ждут.

Ограничение в 13 авторов снято. Знакомые короткие имена сохранены, остальные взяты из экспорта. Аккаунт без имени обозначен «Удалённый аккаунт». Разные аккаунты автоматически не объединяются. Это авторы в архиве, не список нынешних участников группы. Человек без сообщений в архиве тоже может играть.

Фильтры: 60–300 символов, минимум 20 букв; без ссылок, упоминаний, телефонов, команд, пересылок и медиа. Это случайная переписка, а не отредактированная подборка смешных фраз.

Вопросы выбираются только из сообщений **старше двух календарных месяцев** относительно текущего времени по Москве. Например, 15 октября в 12:00 доступны сообщения до 15 августа в 12:00. Свежие фразы внутри уже загруженного архива станут доступны позже автоматически. Переписка после даты экспорта не добавляется; для неё понадобится новый экспорт.

Сначала случайно выбирается автор из доступных, затем его фраза. Так самые активные не доминируют из-за количества сообщений. Один текст одному игроку повторно не выдаётся. Если запас исчерпан, нужно дождаться возрастного порога для более свежих сообщений архива или добавить новый архив.

## Правила и рейтинг

- Раундов и лимита вопросов нет. Четыре варианта имени, затем «Ещё одну».
- Пропуска нет. Следующий вопрос только после ответа. Выход в меню, смена игры и перезапуск не меняют текущую фразу.
- До 20 ответов показываем количество ответов и верных, без процентов.
- Начиная с 20 — точность и отдельный рейтинг. Сортировка по точному проценту правильных ответов, затем по числу ответов (больше — выше). При полном равенстве — стабильный порядок по ID. На экране процент округлён до одного знака.
- `/stats` — личная статистика; `/carousel_top` и кнопка в игре — рейтинг карусели; `/top` — прежние рейтинги и команда перехода к карусели.
- Повторная команда заменяет только карточку своего типа. Приглашение, рейтинг выпусков и рейтинг карусели сохраняются независимо. При невозможности удаления бот пробует редактирование; при отказе обеих операций отправляет новое сообщение.

Три прежних выпуска, их вопросы, попытки и результаты не менялись. Если уже установлена предыдущая версия карусели, накопленный прогресс, статистика и текущий вопрос тоже сохраняются. Сообщения, которые она уже успела записать, не удаляются; дальнейшая запись отключена.

## Запуск и хранение

Railway: polling, одна реплика. Webhook, порт и HTTP healthcheck не нужны. Volume `/data`, `DB_PATH=/data/quiz.sqlite3` для нового сервиса; при обновлении оставьте существующий путь. `RAILWAY_VOLUME_MOUNT_PATH` задаётся Railway автоматически. Токен храните в Variables. Без Volume или при пути вне него бот отказывается запускаться.

Не удаляйте Volume. Резервные копии SQLite делайте через SQLite backup API или резервное копирование Volume: при работе свежие данные могут находиться в WAL.

Локально, Python 3.12+:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Укажите BOT_TOKEN в .env
python bot.py
```

Не запускайте второй процесс с токеном работающего Railway-бота. Для тестов Telegram и токен не нужны:

```sh
python -m unittest discover -s tests -v
python -m compileall -q bot.py storage.py questions.py config.py carousel.py
```
