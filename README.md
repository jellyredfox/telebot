# Я такого не говорил — запуск без спойлеров

В личном меню три пункта:

- «Закончи фразу» — прежние 10 вопросов.
- «Кто это сказал? · Выпуск 1» — прежние 10 вопросов.
- «Кто это сказал? · Выпуск 2» — 10 новых одобренных цитат, отдельная попытка и рейтинг.

**Обновление действующего бота:** замените файлы в той же папке репозитория, включая новый `author-data-v2.json` и обновлённый Dockerfile. Отправьте изменения через GitHub Desktop: Commit → Push origin. Сохраните существующий Volume и текущее значение `DB_PATH`. ID старых игр и их вопросы не менялись: результаты и незаконченные попытки продолжают работать. Новую базу создавать не нужно.

## Обновление на Railway

1. Перед загрузкой файлов сделайте репозиторий **приватным** или используйте новый приватный репозиторий: `quiz-data.json`, `author-data.json` и `author-data-v2.json` содержат цитаты и ответы, `participants.json` — соответствие Telegram ID и имён. Полного экспорта переписки в проекте нет. Не открывайте эти файлы, если хотите пройти без спойлеров.
2. Замените файлы проекта содержимым этой папки. Новые обязательные файлы: `config.py`, `quiz-data.json`, `author-data.json`, `author-data-v2.json`, `participants.json`; Dockerfile тоже обновлён. Токен хранится только в Railway Variables, не в GitHub.
3. Подключите **Volume к сервису бота**, Mount Path `/data`.
4. Variables: `BOT_TOKEN` — прежний токен; `DB_PATH=/data/quiz.sqlite3`. Railway автоматически добавит `RAILWAY_VOLUME_MOUNT_PATH`; вручную создавать эту переменную не надо.
5. Примените изменения кнопкой **Deploy / Apply changes**. Одна реплика; одновременно запускать второй процесс с тем же токеном нельзя. HTTP healthcheck, домен и порт не нужны.
6. После запуска отправьте `/quiz@имя_бота` в группе. Старые и новые приглашения ведут в личку к выбору игры и выпуска. `/top` покажет три отдельных рейтинга.

**Без Volume на Railway бот теперь отказывается запускаться.** Если `DB_PATH` указывает за пределы Volume, он тоже остановится с понятным сообщением. Локально по умолчанию используется `data/quiz.sqlite3`. Сохранение зависит от сохранности самого Volume: не удаляйте его, делайте резервные копии.

Если в старом контейнере ещё есть нужная база, перенесите её до пересоздания контейнера. Подключение нового пустого Volume не восстанавливает уже утраченные данные. Если старая база уже на Volume, оставьте тот же путь: результаты «Закончи фразу» продолжают отображаться, рейтинг «Кто это сказал?» хранится отдельно.

## Что видят участники

- В группе бот заменяет только повторный ответ того же типа: `/quiz` — прежнее приглашение, `/top` — прежний рейтинг, `/help` (и `/start` в группе) — прежние правила, `/stats` — прежнюю подсказку о личной статистике. Приглашение и рейтинг остаются рядом. На карточках есть кнопка «Пройти лично».
- Нажатие кнопки открывает личный чат; пользователь нажимает «Начать» и выбирает игру и выпуск. Прохождение, пояснения и итоги — только там. Автоматических сообщений о завершении в группу нет.
- Вопросы и варианты перемешиваются один раз и сохраняются в SQLite. Можно уйти в середине вопроса, вернуться через `/quiz`, продолжить после рестарта. Следующий вопрос — по кнопке, таймера нет.
- После ответа бот раскрывает правильный вариант, автора и дату. В «Кто это сказал?» автор до ответа присутствует только среди четырёх равноправных вариантов. В основном редактируется одно личное сообщение.
- 1 балл за верный ответ, 0 за неверный. Один ответ на вопрос, одна попытка в каждом выпуске на аккаунт в группе. Рейтинг появляется только после всех 10 ответов. Равные баллы — одинаковое место; время прохождения не учитывается.
- `/top` работает и в личке (последняя выбранная группа), и в группе. Показывает три отдельных рейтинга, до 20 участников в каждом, то есть все 13 заданных имён поместятся. `/stats` показывает личный прогресс всех выпусков. Кнопка «Выбрать игру» возвращает к меню без потери ответа или прогресса. Пройденную игру можно открыть, чтобы увидеть свой итог, но не пройти повторно.
- Имена: Оля, Саша, Саня, Лена, Колян, Дима, Лиза, Артем Г., Артем К., Оксана, Костя, Даша, Вика. Они привязаны к ID из экспорта, а не к меняющемуся нику. Для неизвестного аккаунта используется его имя в Telegram. Дополнительные аккаунты автоматически не объединяются.

## Удаление сообщений: границы

Telegram обычно разрешает удаление сообщений младше 48 часов. Если удалить прежнюю карточку нельзя, бот попробует отредактировать её, не создавая новую. Если Telegram запретит и удаление, и редактирование, бот отправит новую карточку и запишет ограничение в журнал; старую нужно удалить вручную.

ID каждой карточки хранится в SQLite отдельно по группе и типу, поэтому эта логика переживает рестарт. Одновременные команды в одной группе обрабатываются последовательно. Команды самих участников бот не удаляет. При первом обновлении с версии, которая хранила одну общую карточку, бот оставляет её нетронутой: определить её тип по старой базе нельзя. Если она окажется лишней, удалите её один раз вручную. Дальше повторные ответы отслеживаются раздельно. В группе с темами сохраняется по одной карточке каждого типа на всю группу. Не закрепляйте эти карточки: при повторном вызове той же команды они могут быть удалены.

[Ограничения удаления в Telegram](https://core.telegram.org/bots/api#deletemessage). [Постоянное хранилище Railway](https://docs.railway.com/volumes).

Ссылка из группы — приглашение: любой получивший её может пройти игру и посмотреть рейтинг. Проверки членства нет. Права администратора для отправки и удаления собственных новых сообщений в группе не требуются.

## Локальный запуск

Python 3.12+:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Укажите BOT_TOKEN в .env
python bot.py
```

Windows: `.venv\Scripts\activate` и `copy .env.example .env`.

## Проверка сохранности перед игрой

Чтобы не раскрывать себе вопросы, можно сначала вызвать `/quiz` только в отдельной тестовой группе, скопировать ссылку приглашения, перезапустить сервис и убедиться, что та же ссылка работает и после рестарта. Полную проверку прогресса пусть проведёт один доброволец: несколько ответов → рестарт → `/stats` и `/quiz` → тот же прогресс. Не перезапускайте рабочую игру ради проверки, если участники уже начали.

Для резервного копирования используйте backup Volume или SQLite backup API. Не копируйте только основной файл SQLite во время работы: свежие записи могут быть в WAL.

## Автоматические проверки

```sh
python -m unittest discover -s tests -v
python -m compileall -q bot.py storage.py questions.py config.py
```

Тесты не выводят правильные ответы. ID всех выпусков заданы в questions.py; не меняйте их при обычном обновлении. Старые кнопки «Закончи фразу» продолжают работать. Кнопки самой первой викторины про Толкина отклоняются. Проверки покрывают две независимые игры, повторные ответы, рестарт, рейтинги, сохранение 9/10 и очистку групповой карточки.
